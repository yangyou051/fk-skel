# fk-skel —— 新月杀（FreeKill）骨骼皮肤拓展包

给《新月杀 / FreeKill》加 **Spine（骨骼）动态皮肤**，以**拓展包**形式实现，
**不改核心一个字节** ✓

---

## 这是什么

* 把武将立绘换成**会动的骨骼皮肤**（呼吸、飘动、入场、技能、攻击动画）
* 自带**换肤面板**：列表预览 + 预览取景微调 + 对局取景 + 场上动画 + 出场动画，**各自独立可调**
* **每人独立**：你选的皮肤和微调只存本机（`client.db`），不影响别人
* 支持**多形态切换**：同一角色的不同形态可按条件自动切换（例：张琪瑛按体力在「九州春回」↔「九州春回2」间切换）

---

## 安装

### 方式一：游戏内一键装（推荐）

1. 启动游戏
2. 主界面 → **包管理**（Package Manage）
3. 底部输入框粘贴本仓库地址：
   ```
   https://github.com/yangyou051/fk-skel
   ```
4. 点 **Install From URL**
5. 重启游戏

> ⚠ 包名必须保持 `fk-skel`（内部路径是固定的），所以**仓库名请用 `fk-skel`**。

### 方式二：手动放置

把本仓库整个目录放到：

```
<游戏目录>/packages/fk-skel/
```

确认存在 `<游戏目录>/packages/fk-skel/init.lua` 即可。

---

## 启用

装好**还需要两步启用**：

1. **设置 → UI 设置 → lunarltk → 选 `骨骼皮肤UI（原版界面+骨骼支持）`**
   （一个桌游只能选一个 UI 包，所以必须在这里切）
2. 进对局后按 **`Ctrl+J`** 打开换肤面板，给武将选一套皮肤

## 目录结构

```
init.lua                  包入口：注册 UI 包 / 大厅入口 / 扫描皮肤清单
config.json               本地配置
qml/
  SkelHost.qml            对局内宿主（原版界面 + 叠加骨骼头像层）
  SkelAvatar.qml          骨骼头像渲染（背景层 + 人物层）
  SkelPicker.qml          换肤面板
  SkelField.qml           场上大动画（技能 / 攻击）
  SkelButton.qml          「换肤」按钮
  SkelProbe.js            探针（读核心界面结构，算坐标）
  SkelStore.js            存档注入 + 每人独立的皮肤/微调表
skins/<皮肤key>/
  skin.lua                皮肤定义（骨架名 / 动画名 / 取景 / 场上动画）
  image/skins/*           .skel / .atlas / .png 素材
```

## 加自己的皮肤

见 [`导入皮肤.md`](导入皮肤.md) 和 [`踩坑记录.md`](踩坑记录.md)。

**要点**：
* 素材格式必须是 **Spine `.skel` 二进制**（`.json` 不行）
* 骨架版本建议 **3.6.x**（实测这一代最稳）
* `skin.lua` 里 `field_anim` **绝不能**填待机动画名（否则发动技能播待机）

---

## 已知限制

| 限制 | 说明 |
|---|---|
| **只影响你自己** | 骨骼皮肤显示在你本机的武将牌上；别人看你仍是原版立绘 |
| **`.json` 骨架不支持** | 核心只读 `.skel` 二进制 |
| **表情图不在本包内** | 表情走核心 `image/emoji/` 路径，装不进拓展包；需要单独替换 |

---

## 兼容性

* 目标游戏：**新月杀 / FreeKill**（Qt6）
* 依赖：核心自带的 `Spine` Qt 插件（不需要额外安装）
* 不改核心文件，随时可拔掉（把 `packages/fk-skel` 改名加 `.disabled` 即停用）
